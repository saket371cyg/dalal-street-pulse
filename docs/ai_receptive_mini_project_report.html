1.1 Problem Definition

In India's rapidly expanding financial sector, over 160+ million retail Demat accounts have been opened across CDSL and NSDL. However, the majority of retail and first-time investors face severe information asymmetry and cognitive overload. Key dimensions of the real-world problem include:

  • Fragmented & Disconnected Exchange Tickers: Companies are listed on both the National Stock Exchange of India (NSE) and BSE Ltd. with divergent identifiers (e.g. RELIANCE on NSE vs. Scrip Code 500325 on BSE). Retail users struggle to reconcile dual-listed stocks and corporate actions.
  • Western Bias in Existing Fintech Tools: Global platforms (Yahoo Finance, TradingView) default to Western number grouping (millions/billions), ignoring the domestic Indian numbering system (Lakhs and Crores), and fail to track official NSE trading session timings (Pre-open 09:00–09:15, Equity 09:15–15:30, Post-close 15:30–16:00, and exchange holidays).
  • Dense, Inaccessible Financial Statements: Quarterly P&L statements, balance sheets, and SEBI regulatory filings span hundreds of pages of complex accounting jargon. Retail investors lack the institutional expertise to compute return metrics (ROCE, ROE, Debt/Equity) or benchmark valuation multiples against sector peers.

1.2 Target Users

Primary Target: Novice Retail Investors Demographic: 21–32 Yrs
Young working professionals, college graduates, and first-time earners entering equities via SIPs or discretionary stock picks. They require intuitive visual analytics, jargon-free explanations, and native currency formatting (`₹`) to build long-term wealth without falling into speculative penny-stock traps.
Secondary Target: Active Working Traders Demographic: 28–48 Yrs
Salaried individuals and self-employed investors who actively monitor stock watchlists and indices (NIFTY 50, SENSEX, NIFTY Bank) but cannot dedicate entire trading hours to manual chart monitoring. They depend on automated price alerts, post-market executive briefings, and institutional flow (FII/DII) tracking.

1.3 How AI Assists in Solving the Problem (AI-Receptive Design)

An AI-Receptive software architecture is designed from the foundation to incorporate machine learning and large language models as collaborative co-processors rather than superficial chatbots. Dalal Street Pulse integrates AI across three core dimensions:

  • Grounded Fundamental Health Scoring: Instead of asking LLMs to guess stock fundamentals, the system deterministically calculates financial ratios (P/E difference vs industry median, ROCE > 20%, Debt-to-Equity < 0.5) and feeds structured metrics to Gemini AI to generate an objective 1–10 Fundamental Health Score and an Undervalued / Fairly Valued / Overvalued verdict.
  • Automated Post-Market Daily Briefings (16:30 IST): An event-driven Inngest workflow triggers daily at market close, ingesting closing prices, sector gainers/losers, and RBI/macro news. The AI synthesizes this data into an executive 60-second summary explaining why markets moved.
  • Natural Language Financial Literacy Assistant: Complex balance sheet items and corporate disclosures are automatically translated into plain, relatable business summaries, empowering retail investors with institutional-grade understanding.

1.4 Limitations & Risks of Using AI in this Solution

Identified Critical Risk: Hallucinatory Financial Bias & Non-Advisory Compliance
Financial markets are non-deterministic and susceptible to black swan events (e.g. geopolitical shocks, unexpected RBI rate hikes). If an unconstrained AI model hallucinates earnings growth or projects price targets, retail investors could incur severe financial losses.

Mitigation Architecture: Dalal Street Pulse implements Strict Grounded Generation—the AI is programmatically forbidden from predicting speculative price targets and must cite verified exchange filings. Additionally, persistent statutory SEBI Non-Advisory Disclaimers are rendered on all AI views to ensure full regulatory adherence.

4.3 Code Artifact Example: Grounded Valuation Scoring (`lib/ai/index.ts`)

export async function analyzeIndianStock(symbol: string): Promise<AIAnalysisResult | null> {
  const quote = await getStockQuote(symbol);
  const fund = await getStockFundamentals(symbol);
  if (!quote || !fund) return null;

  // Grounded Deterministic Valuation Benchmarking
  let valuationVerdict: 'Undervalued' | 'Fairly Valued' | 'Overvalued' = 'Fairly Valued';
  let healthScore = 7;

  if (fund.peRatio < fund.industryPE * 0.85 && fund.roe > 15) {
    valuationVerdict = 'Undervalued';
    healthScore += 2;
  } else if (fund.peRatio > fund.industryPE * 1.35) {
    valuationVerdict = 'Overvalued';
    healthScore -= 1;
  }

  if (fund.debtToEquity < 0.5) healthScore += 1;
  if (fund.roce > 20) healthScore += 1;
  healthScore = Math.min(10, Math.max(1, healthScore));

  return { symbol: quote.symbol, valuationVerdict, fundamentalHealthScore: healthScore };
}
